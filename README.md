# CyberGlass Hyprland Dotfiles

A modern, high-performance, live-refresh **Hyprland** desktop configuration designed for Arch Linux power users, developers, and cybersecurity enthusiasts. 

Featuring custom liquid-glass backdrop re-sampling via **`hyprglass`** and responsive Quickshell widgets.

---

## ⚡ Features

- 💎 **Live-Refresh Liquid Glass (`hyprglass`)**: Real-time backdrop sampling and dynamic blur behind Quickshell widgets, animated wallpapers, and video layers.
- 🎨 **Matugen Dynamic Color System**: Material You palette generation synced automatically across your desktop environment.
- 🛠️ **Arch Linux & Security Optimized**: Clean, lightweight scripts tailored for rapid terminal deployment, development, and penetration testing workflows.
- 🎵 **Quickshell Music & Control Center**: Modern widgets built for multi-monitor, high-DPI scaling setups.

---

## 🚀 Installation

To install or update on Arch Linux:

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/rayanelhabib/cyberglass-hyprland/master/install.sh)"
```
